# Передача пробного обучения burdaAI на другой ПК

Ты принимаешь ответственность за подготовку, запуск после разрешения владельца и приёмку пробного обучения C05. [Репозиторий Neuroslop League](https://github.com/Neuroslop-League/burdaAI)

## Проект и структура

burdaAI — двуязычная языковая модель Neuroslop League. Русский язык приоритетный. Стартовая цель обучающего корпуса — 70% русских и 30% английских текстовых токенов. Python и PyTorch используются для модели и обучения, Rust — для инференса и инфраструктуры. Цель запуска на 1 ГБ VRAM относится к инференсу. Пробное обучение готовится для RTX 5070 с 12 ГБ VRAM.

1. Прочитай [README](../README.md), [контракты](contracts.md), [языковой стек](stack.md), [спецификацию модели](model-spec.md), [декодер](decoder.md), [токенизатор](tokenizer.md), [подготовку данных](data.md) и [инструкцию C05 на ревизии подготовки](https://github.com/Neuroslop-League/burdaAI/blob/f6ff49c/docs/training.md).
2. На выбранной ревизии проследи путь от `scripts/c05_pilot.py` и `configs/c05-pilot.json` до декодера в `burdaai/`, токенизатора в `artifacts/c02-v1/` и манифеста в `data/c04-pilot/shards/`. Сверь документацию с реализацией.
3. Проверь состояние [PR #12 с пилотными шардами](https://github.com/Neuroslop-League/burdaAI/pull/12) и [PR #13 с подготовкой C05](https://github.com/Neuroslop-League/burdaAI/pull/13). Выбери ревизию, которая содержит оба изменения. Зафиксируй её SHA, пути к данным и контрольным точкам и зависимые от оборудования настройки. Правки передавай через PR из отдельной ветки.

## До разрешения на запуск

- Уточни ОС, драйвер, модель карты, доступную VRAM, объём RAM и свободное место на диске. Подготовь окружение по инструкции C05. В подготовленном PR указан PyTorch 2.8.0 с CUDA 12.8.
- Выполни на CPU `python -m scripts.c05_pilot check`. Сверь контрольные суммы шардов, идентификатор токенизатора, правое дополнение, сдвиг целей и контрольный loss. Ожидаемое число действительных целей для train, validation и test — 3235, 2232 и 2521.
- Дождись отдельной команды владельца перед GPU-проверками и обучением. Авторские тексты относятся к основному корпусу. Для прогона C05 используй пилотные шарды.

## После разрешения

Проверь native BF16 на фактическом окружении и доступную память. Сохрани BF16 Mixed Precision, FP32-мастер-веса и FP32-состояния AdamW в системной RAM.

Расчёт для стартового профиля — 10,5–11,5 ГиБ VRAM, 16–17 ГиБ RAM в рабочем цикле и до 28 ГиБ RAM плюс ОС и приложения при восстановлении. Это оценки из PR #13. Сверь запас перед запуском и замерь фактические пики отдельно для обучения и восстановления.

Стартовые параметры — длина 32, микропакет 1 и накопление 1. Команда из корня репозитория в подготовленном окружении:

```bash
python -m scripts.c05_pilot train --length 32 --microbatch 1 --accumulate 1 --output runs/c05-rtx
```

## Приёмка и передача результата

- Подтверди конечные loss и градиенты, изменение весов и FP32-состояния оптимизатора после обновления.
- Проверь восстановление из контрольной точки с правильного шага и позиции в данных. Сопоставь продолжение с непрерывным прогоном по критериям C05.
- При ошибке зафиксируй этап, команду, конфигурацию и сообщение. Предложи корректировку в пределах утверждённых требований C01.
- Передай владельцу SHA коммита, версии окружения, команды, пиковые VRAM и RAM, время шага, результат восстановления и ограничения. Внеси подтверждённые результаты в `docs/training.md`.
- Полное обучение требует отдельного решения владельца по итогам пробного запуска.
