# C07.5. Протокол сравнения CPU FP32

До первого сравнения устанавливаем максимальную абсолютную ошибку 1e-3 по всем элементам матрицы логитов, без относительного допуска. Проверяем четыре последовательных префикса одного запроса с BOS, на каждом требуем точного совпадения greedy ID (первый индекс максимума), конечности всех значений и совпадения формы. Эталон — Python Decoder.eval() под inference_mode, кандидат — Rust CPU FP32. Оба читают одни и те же неквантованные синтетические веса полной формы C01 и общий токенизатор. Остановку по EOS и границе окна проверяем отдельно от численного допуска.
