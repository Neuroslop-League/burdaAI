# C06. Полное обучение, оценка и выпуск

Цель — выпустить воспроизводимый комплект burdaAI с оценкой на русском и английском и подтверждённым запуском на слабом ПК с дискретной видеокартой с 1 ГБ VRAM.

## Протокол оценки и запуск

**C06.1.** До полного прогона зафиксировать версии данных, метрики, базовую линию и пороги. Для языковой модели измерить среднюю кросс-энтропию по действительным целям и перплексию на одинаковом токенизаторе и наборе примеров. Отчёт включает результаты отдельно для русского и английского и число токенов в каждой части. Добавить фиксированные задания генерации с заранее заданными правилами проверки. Validation применяется для настройки и выбора контрольной точки, test — для итогового решения. Зафиксировать допустимое ухудшение квантованного варианта относительно эталонных весов на тех же примерах.

**C06.2.** После пробного запуска C05 согласовать лимит времени, число шагов или токенов, график оценки, правило выбора контрольной точки и критерии досрочной остановки. Сохранить ссылки на конфигурацию и версии входов, журналы, точки восстановления и причину окончания прогона.

**C06.3.** Провести итоговую оценку выбранной точки по утверждённому протоколу. Для каждой метрики показать порог, измерение и результат. Сравнить эталонный и квантованный варианты. Провал порога блокирует выпуск до устранения причины и повторной оценки. Результаты итогового набора не используются для подбора параметров. Если исправление выбрано с учётом результатов test, для новой итоговой оценки резервируется независимый набор по тому же протоколу.

## Проверка на 1 ГБ VRAM

Следовать [C01.4](model-spec.md#c014-локальный-запуск-на-слабом-оборудовании). До прогона зафиксировать модель дискретной карты, доступную VRAM, CPU, RAM, ОС, драйвер и backend. Сначала сравнить доступные варианты формата и размещения, включая 4-битное хранение, если его поддерживает выбранная конфигурация. Проверить гибридный режим по журналу размещения и наблюдаемым вычислениям на GPU.

В чистом окружении загрузить артефакт и выполнить генерацию для входа из 256 токенов и 64 последовательных шагов с отключённой ранней остановкой. Измерить пик VRAM при загрузке и генерации, пик RAM, время до первого токена и скорость после первого токена. Если backend использует общую память, указать её отдельно. Выполнить проверку максимальной подтверждённой длины на этой конфигурации и опубликовать фактический предел.

## Комплект выпуска

**C06.4.** Подготовить комплект со следующими проверяемыми элементами. Оценку выполняет Python, запуск на 1 ГБ VRAM проверяется через Rust CLI из C07.7.

| Элемент | Содержимое и проверка |
| --- | --- |
| Веса и конфигурация | Версия модели, версия архитектуры, форматы весов и контрольные суммы. Совместимость с C03 проверяется загрузкой |
| Токенизатор | Артефакт и манифест. `tokenizer_id` и `vocab_size` совпадают с конфигурацией |
| Инструкция запуска | Команды установки, загрузки и генерации, версии backend, параметры распределения CPU/GPU и типичные ошибки |
| Отчёт | Происхождение данных в допустимом для публикации объёме, конфигурация обучения, результаты оценки, замеры оборудования и известные ограничения |
| Манифест выпуска | Идентификатор выпуска, идентификаторы и контрольные суммы всех файлов, условия использования и ссылки на отчёт и инструкцию |

Выпуск принят после успешной загрузки и генерации независимо от рабочего окружения разработчика на описанной эталонной конфигурации. Совместимость для других систем указывается по результатам отдельных проверок. Конкретная карта на 1 ГБ, измеренные показатели и пороги выпуска пока открыты.
